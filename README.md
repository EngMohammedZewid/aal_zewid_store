# 🏬 إدارة المتجر برو (StoreManager Pro)
**نظام إدارة المتاجر ونقاط البيع الشامل والمصمم كلياً باللغة العربية (RTL)**

## 🌟 نبذة عامة
برنامج **إدارة المتجر برو** هو تطبيق سطح مكتب متطور، مصمم خصيصاً لتلبية احتياجات أصحاب المتاجر والمشاريع التجارية في الوطن العربي. يتميز البرنامج بواجهة مستخدم عصرية تعتمد على **التصميم المسطح الداكن والفاتح**، وتدعم المحاذاة من اليمين إلى اليسار (RTL) بشكل أصلي واحترافي.

لا يتطلب البرنامج أي اشتراكات سحابية أو تعقيدات في إعداد الخوادم، حيث تعمل جميع وظائفه (*المخزون، نقاط البيع، العملاء، المورّدون، والتقارير المالية*) على قاعدة بيانات محلية فائقة السرعة من نوع **SQLite**، مما يضمن خصوصية وأمان بياناتك بنسبة 100%.

## 🚀 استعراض المزايا والخصائص

## 🆕 آخر التحديثات (الإصدار الحالي)
تمت إضافة ثلاث مزايا تشغيلية ومالية رئيسية إلى التطبيق:

### 1. جلسات الكاشير
* لا يمكن تنفيذ بيع جديد بدون **جلسة كاشير مفتوحة**.
* كل جلسة تسجل:
  * الرصيد الافتتاحي.
  * وقت الفتح والإغلاق.
  * الرصيد المتوقع عند الإغلاق.
  * الرصيد الفعلي المدخل من المستخدم.
  * فرق العهدة (**متوازن / زيادة / عجز**).
* يمكن استعراض سجل الجلسات وفتح تقرير تفصيلي لكل جلسة.

### 2. فواتير الاسترجاع
* تم دعم **الاسترجاع الكامل والجزئي**.
* لا يتم تعديل الفاتورة الأصلية أو حذفها.
* كل استرجاع يسجل كوثيقة مالية مستقلة مرتبطة بالفاتورة الأصلية.
* يتم:
  * إعادة الكمية إلى المخزون.
  * احتساب الضريبة والخصم بشكل نسبي من القيم الأصلية.
  * خصم نقاط الولاء المرتبطة بقيمة الاسترجاع دون السماح بأن تصبح سالبة.

### 3. مصروفات الجلسة اليومية
* يمكن تسجيل مصروفات مرتبطة بالجلسة المفتوحة فقط.
* المصروف النقدي يؤثر على الرصيد النقدي المتوقع داخل الدرج.
* المصروف غير النقدي يظهر في التقارير ولا يخصم من النقدية الفعلية.


### 1. 📊 لوحة التحكم التفاعلية
* **نظرة عامة حية:** عرض فوري ومباشر لإيرادات مبيعات اليوم، إجمالي عدد المنتجات في الكتالوج، تنبيهات نواقص المخزون، وإجمالي القيمة المالية للمخزون الحالي.
* **إجراءات سريعة:** أزرار اختصار مباشرة للبدء في فاتورة مبيعات جديدة (POS) أو إضافة منتج جديد إلى الكتالوج.
* **سجل الفواتير:** جدول تفاعلي يعرض أحدث العمليات والفواتير الصادرة. يمكنك **النقر مرتين على أي فاتورة** لفتح إيصال تفصيلي يعرض المنتجات المباعة، الكميات، وطريقة الدفع.

### 2. 🛒 شاشة نقطة البيع (POS) وإصدار الفواتير
* **بحث فائق السرعة:** إمكانية البحث عن المنتجات عن طريق قراءة **الباركود (SKU)** أو كتابة اسم المنتج، أو ببساطة النقر على المنتجات من جدول الكتالوج البصري.
* **إدارة سلة المشتريات:** تعديل الكميات بسهولة، حساب المجموع الفرعي، تطبيق خصم إضافي ($)، وحساب ضريبة القيمة المضافة (8%) تلقائياً.
* **خيارات دفع متعددة:** تسجيل الدفع عبر *الكاش (نقدي)، بطاقة الائتمان، الدفع الإلكتروني (مدى/فوري)، أو شبكة مدى*.
* **ربط مباشر بالعملاء:** اختيار عميل مسجل أو إضافة عميل جديد مباشرة من شاشة الكاشير لربط نقاط الولاء.
* **خصم المخزون التلقائي:** بمجرد اعتماد الفاتورة، يتم خصم الكميات المباعة تلقائياً من الأرفف ومخزون المتجر الفعلي.
* **شريط جلسة واضح أعلى شاشة POS:** يعرض رقم الجلسة، وقت الفتح، الرصيد الافتتاحي، والرصد النقدي المتوقع الحالي.
* **إغلاق جلسة مع مطابقة عهدة:** احتساب تلقائي للمبيعات النقدية، المرتجعات، المصروفات، والفرق النهائي.

### 2.1. فاتورة الاسترجاع من شاشة POS
* البحث عن الفاتورة الأصلية برقمها.
* عرض الكميات المباعة والمسترجعة سابقاً والمتبقي المتاح للاسترجاع.
* دعم استرجاع صنف واحد أو عدة أصناف في نفس العملية.
* دعم اختيار طريقة الاسترجاع:
  * `كاش`
  * `بطاقة ائتمان`
  * `دفع إلكتروني`
  * `نفس طريقة الدفع الأصلية`
* عرض فاتورة استرجاع مستقلة بعد نجاح العملية.

### 2.2. مصروفات الجلسة من شاشة POS
* تسجيل مصروف جديد داخل الجلسة المفتوحة.
* استعراض مصروفات الجلسة الحالية.
* عرض تفاصيل كل مصروف.
* منع حذف المصروفات بعد إغلاق الجلسة.

### 3. 📦 إدارة المخزون وكتالوج المنتجات
* **بطاقة منتج شاملة:** تسجيل أسعار التكلفة، أسعار البيع، الكمية الحالية المتوفرة، وتحديد **حد تنبيه النواقص** لكل منتج على حدة.
* **تنبيهات النواقص الذكية:** المنتجات التي تصل أو تقل عن حد التنبيه يتم تمييزها تلقائياً **باللون البرتقالي/الأصفر** في الجدول للفت انتباه المدير لطلب إعادة التموين.
* **تعديل المخزون السريع:** نافذة مخصصة لتصحيح أو جرد كمية المخزون الفعلي بضغطة زر دون الحاجة لتعديل كامل تفاصيل المنتج.
* **إدارة التصنيفات:** تنظيم المنتجات تحت تصنيفات مخصصة (*مثل: ملابس وأزياء، إلكترونيات، أدوات منزلية، مشروبات*).

### 4. 🚚 المورّدون وأوامر الشراء (إعادة التموين)
* **دليل شركات التوريد:** حفظ بيانات المورّدين، أسماء المندوبين، أرقام الهواتف، والعناوين الجغرافية.
* **إنشاء أوامر الشراء:** طلب منتجات جديدة لإعادة ملء المخزون مع تحديد أسعار التكلفة للوحدة.
* **الاستلام وإضافة المخزون التلقائي:** عند وصول البضاعة، ما عليك سوى تحديد أمر الشراء والضغط على **"تسجيل كـ 'تم الاستلام'"** — سيقوم البرنامج فوراً بتحديث حالة الطلب وإضافة جميع الكميات المشتراة إلى مخزون المتجر!

### 5. 👥 دليل العملاء ونظام الولاء
* **سجل العملاء:** تسجيل أسماء العملاء، أرقام الهواتف، والبريد الإلكتروني.
* **برنامج نقاط الولاء:** يكتسب العميل نقطة ولاء واحدة تلقائياً مقابل كل 10 دولارات ينفقها في المتجر.
* **أرشيف مشتريات العميل:** بالنقر مرتين على أي عميل في الجدول، تفتح نافذة تعرض كامل تاريخ مشترياته وجميع الفواتير السابقة التي قام بها في متجرك.

### 6. 📈 التحليلات المالية والتقارير التنفيذية
* **ملخص الأداء المالي:** حساب دقيق لإجمالي المبيعات، إجمالي المرتجعات، صافي المبيعات، **تكلفة البضاعة المباعة (COGS)**، تكلفة البضاعة المرتجعة، صافي تكلفة البضاعة، الربح بعد المرتجعات، وإجمالي المصروفات.
* **رسومات بيانية مدمجة:** مدمج بالبرنامج مكتبة **Matplotlib** التفاعلية لتعرض:
  1. رسم بياني (أعمدة) لصافي المبيعات اليومية لآخر 7 أيام بعد خصم المرتجعات.
  2. رسم بياني أفقي لترتيب **أكثر 5 منتجات مبيعاً بعد الاسترجاعات**.
* **تصدير متوافق مع Excel:** إمكانية تصدير سجل موحد للعمليات يشمل البيع والاسترجاع والمصروفات إلى ملف **CSV** بترميز `UTF-8-SIG`.

## 🧱 تحديثات قاعدة البيانات

تمت إضافة الجداول التالية بدون حذف بيانات المستخدم القديمة:

* `pos_sessions`
* `expenses`
* `sale_returns`
* `sale_return_items`

كما تمت إضافة الحقل التالي إلى جدول `sales`:

* `session_id` (اختياري للحفاظ على توافق المبيعات التاريخية القديمة)

### سلوك الترقية (Migration)
عند تشغيل التطبيق:

* يتم إنشاء الجداول الجديدة إذا كانت غير موجودة.
* يتم فحص وجود العمود `sales.session_id` قبل إضافته.
* يتم إنشاء الفهارس الجديدة بشكل آمن باستخدام `CREATE INDEX IF NOT EXISTS`.
* إذا احتاجت قاعدة بيانات قديمة إلى ترقية فعلية، ينشئ التطبيق نسخة احتياطية بصيغة:

```text
store_backup_YYYYMMDD_HHMMSS.db
```

* لا يتم حذف الجداول القديمة.
* لا يتم إعادة زرع البيانات الافتراضية داخل قاعدة بيانات إنتاج موجودة.

## 💰 معادلة النقدية المتوقعة للجلسة

يتم احتساب النقدية المتوقعة داخل درج الكاشير وفق المعادلة التالية:

```text
الرصيد المتوقع = الرصيد الافتتاحي + المبيعات النقدية - المرتجعات النقدية - المصروفات النقدية
```

المدفوعات غير النقدية لا تدخل في رصيد الدرج الفعلي.

## 🌐 تطبيق الويب

نفس وظائف البرنامج (نقطة البيع، المخزون، الوحدات، الجلسات، الاسترجاع، المصروفات، المورّدون، العملاء، والتحليلات) متاحة من المتصفح. منطق المال يبقى في `core/db.py`، وواجهة الويب تتصل به عبر FastAPI.

التشغيل المحلي يحتاج نافذتين:

```bash
pip install -r requirements.txt
python -m uvicorn api.app:app --reload --port 8000
```

```bash
cd frontend
npm install
npm run dev
```

ثم افتح `http://localhost:5173`. الحسابات الأولى، إذا كانت جدول المستخدمين فارغاً:

- المدير: `manager` / `manager123`
- الكاشير: `cashier` / `cashier123`

يمكن تغيير كلمتي المرور عبر `STORE_MANAGER_PASSWORD` و `STORE_CASHIER_PASSWORD` قبل أول تشغيل. غيّرهما بعد الدخول. الكاشير يستخدم لوحة التحكم ونقطة البيع فقط، والمدير يستخدم بقية الشاشات وإدارة المستخدمين.

## 🛠️ التقنيات المستخدمة
* **لغة البرمجة:** Python 3.8+
* **واجهة المستخدم (GUI):** مكتبة `Tkinter` و `ttk` القياسية مع تخصيص احترافي للألوان والخطوط ودعم التمدد التلقائي للشاشات.
* **قاعدة البيانات:** `SQLite3` مع تفعيل كامل لقيود المفاتيح الأجنبية (Foreign Keys) للحفاظ على ترابط البيانات.
* **الرسومات البيانية:** `Matplotlib` مدمجة كلياً داخل نوافذ Tkinter.

## 💻 تعليمات التثبيت والتشغيل

### 1. المتطلبات الأولية
تأكد من وجود بيئة **Python 3.8** أو أحدث مثبتة على جهازك.

### 2. تثبيت المكتبات المطلوبة
افتح موجه الأوامر (*Terminal / Command Prompt*) داخل مجلد المشروع، وقم بتثبيت مكتبة الرسم البياني:

```bash
pip install -r requirements.txt
```

### 3. تشغيل البرنامج
```bash
python3 main.py
```
> 💡 **ملاحظة:** عند تشغيل البرنامج للمرة الأولى، سيقوم تلقائياً بإنشاء ملف قاعدة البيانات (`store.db`) وتغذيته ببيانات افتراضية واقعية (*منتجات، تصنيفات، فواتير، وعملاء*) لتتمكن من تجربة وفحص جميع المزايا مباشرة!

### 4. إعادة تهيئة قاعدة البيانات (Schema Reset)
إذا كنت تريد تفريغ قاعدة البيانات بالكامل وإعادة إنشاء الجداول فارغة وجاهزة لإدخال بيانات جديدة:

```bash
python3 reset_schema.py
```

لاستخدام ملف قاعدة بيانات مختلف:

```bash
python3 reset_schema.py --db-path my_store.db
```

### 5. تشغيل الاختبارات الآلية
```bash
python -m unittest discover -s tests -v
```

## 📦 تحويل البرنامج إلى ملف تنفيذي مستقل (`.exe` أو `.app`)
إذا كنت ترغب في نقل البرنامج وتشغيله على أجهزة الكاشير التي لا تحتوي على بيئة Python، يمكنك تحويل كامل المشروع إلى ملف تنفيذي مستقل باستخدام أداة **PyInstaller**:

### لنظام ويندوز (.exe)
```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --add-data "core;core" --add-data "ui;ui" --name "StoreManagerPro" main.py
```
ستجد تطبيق `StoreManagerPro.exe` جاهزاً للتشغيل المباشر داخل مجلد `dist/StoreManagerPro`.

### لنظام ماك (.app)
```bash
pip install pyinstaller
pyinstaller --noconfirm --onedir --windowed --add-data "core:core" --add-data "ui:ui" --name "StoreManagerPro" main.py
```
ستجد التطبيق المستقل داخل مجلد `dist/StoreManagerPro.app`.
